# 测试与验收清单

本文件记录 v1.3.0 的验证状态：哪些是自动化验证过的，哪些还需要人工过一遍。
提交 PR 前建议先跑一遍「电脑端自动化」部分。

## 电脑端（可自动化）

```powershell
cd pc
go vet ./...
go test ./...
```

覆盖范围：

- [x] 配对码配对 → 带 token 推送 → 记录落库
- [x] 免码配对：`/pair/request` → `/api/approve` → `/pair/status` 拿到 token
- [x] 已配对设备再次请求直接 `approved`（自动重连）
- [x] 心跳下发「文字快送」且只下发一次
- [x] 设备与 token 落盘后重启可恢复
- [x] `/ping` 不返回配对码
- [x] 配对码连续失败 5 次后返回 429

界面层（无头浏览器 + CDP 审计）：

- [x] 四个页面渲染无 JS 报错、无横向溢出、中文无乱码
- [x] 通知流 / 设备卡 / 待确认请求 / 地址列表按数据渲染
- [x] 文本对比度：正文 19.6:1、次要文字 6.2:1、紫块白字 5.6:1（均 ≥ 4.5:1）

## 电脑端（需要人工）

- [ ] 双击 exe 后 Edge 应用窗口的实际观感（无地址栏、图标、缩放）
- [ ] 托盘菜单：打开界面 / 本机地址 / 配对码 / 设备改名 / 最近记录 / 重置配对 / 启动时打开界面 / 退出
- [ ] 「发条文字」→ 手机弹出「来自电脑」通知
- [ ] 关闭界面窗口后程序仍在托盘运行，再次「打开主界面」能重新打开
- [ ] 端口 8787 被占用时能否自动换端口并正常显示

## 手机端（需要真机）

- [ ] 打开 App 3 秒内「附近的电脑」出现电脑名字与 IP
- [ ] 点「连接这台电脑」→ 电脑界面出现「允许连接」→ 允许后手机显示「已连接电脑」
- [ ] 电脑端重启后手机自动重连（不用再点允许）
- [ ] 配对码连接成功；配对码错误时提示「配对码错误」
- [ ] 总开关 / 四个分类开关 / 暂停同步按钮生效
- [ ] 状态通知四种文案（未授权 / 已暂停 / 等待连接 / 已连接）与真实状态一致
- [ ] 微信、短信、其他应用、系统通知四类都能弹到电脑，且 Toast 内容与来源正确
- [ ] 同一来源连续 3 条消息，电脑端旧 Toast 被立即替换
- [ ] 电脑端「发条文字」→ 手机弹「来自电脑 · 小青柠」通知
- [ ] 块面布局在刘海屏 / 小屏上的安全区域与 44dp 触控高度

## 连接与环境

- [ ] 同一 Wi-Fi 下自动发现
- [ ] 笔记本移动热点（192.168.137.x）下自动发现与同步
- [ ] 防火墙放行后手机可连（`fix-firewall.ps1` 或手动 netsh）
- [ ] 手机息屏 10 分钟后恢复亮屏能自动重连

## 已知未验证项

- Android 端未在真机或模拟器上运行过（仅编译通过），UI 观感与部分交互手感需实机确认。
- Windows Toast 的显示效果未逐条目视（逻辑沿用 v1.2.2）。
- 首次运行 Windows 放行防火墙的耗时与系统环境强相关，本机实测一次约 30 秒、之后约 1 秒。
